# Yandex Disk Sync for Obsidian

Двусторонняя синхронизация Obsidian-хранилища через REST API Яндекс.Диска. Плагин работает на Windows, Linux, macOS, Android и iOS без Node.js API.

## Возможности

- двусторонняя синхронизация заметок и вложений;
- отображение прогресса и текущего файла;
- три вида прогресса с предпросмотром в настройках: графическая полоска с процентами (по умолчанию), только текст и круговой индикатор;
- ограниченная параллельная обработка для ускорения синхронизации;
- быстрый повторный запуск за счёт кеша размера, времени изменения и SHA-256;
- защита от перезаписи файла, изменённого во время синхронизации;
- конфликтные копии при одновременном изменении на разных устройствах;
- удаление пользовательских файлов через корзину;
- блокировка с владельцем и heartbeat для нескольких устройств;
- повторы запросов при `429`, сетевых ошибках и ошибках сервера;
- ручной запуск по кнопке или автоматическая синхронизация по расписанию;
- настраиваемые исключения.

## Установка через BRAT

1. Установите плагин BRAT в Obsidian.
2. Выполните команду **BRAT: Add a beta plugin for testing**.
3. Укажите `stash1ho/yandex-disk-sync`.
4. Включите **Yandex Disk Sync** в списке сторонних плагинов.

Также можно скачать `main.js`, `manifest.json` и `styles.css` из последнего релиза и положить их в:

```text
<vault>/.obsidian/plugins/yandex-disk-sync/
```

## Настройка

1. Создайте OAuth-токен Яндекс.Диска с минимально необходимым доступом.
2. Вставьте токен в настройках плагина.
3. Для приложения с доступом только к своей папке оставьте `app:/vault`.
4. Нажмите **Проверить подключение**.
5. Оставьте параллельность `4`. Для слабого телефона можно выбрать `2`, для компьютера — `6`.

Токен хранится в локальном `data.json`. Папка `.obsidian` всегда исключается из синхронизации.

В настройке **Режим синхронизации** доступны два варианта:

- **Вручную** — синхронизация только по кнопке на боковой панели или команде «Синхронизировать сейчас». Редактирование заметок, запуск Obsidian и возврат в приложение не вызывают синхронизацию.
- **По расписанию** — первый запуск через заданное количество минут, затем такая же пауза после завершения предыдущего запуска. Интервал — целое число от 1 до 1440 минут. Ручная кнопка также доступна и отсчитывает интервал заново.

При смене режима отложенные запуски отменяются; уже начатая синхронизация завершается. Расписание работает, пока приложение активно; если таймер был приостановлен в фоне, просроченная синхронизация запускается при возврате в Obsidian. Повторные нажатия во время синхронизации не создают очередь запусков.

Для новой установки по умолчанию выбран ручной режим. При обновлении прежний интервал `0` переводится в ручной режим, положительный интервал — в режим по расписанию.

В настройке **Вид прогресса** можно выбрать **Полоска и проценты**, **Только текст** или **Круговой индикатор**. Предпросмотр обновляется сразу; выбор сохраняется между запусками. По умолчанию используется графическая полоска. Во время проверки файлов, пока их количество неизвестно, показывается неопределённый прогресс без процентов.

## Конфликты и удаления

Если один файл изменён на двух устройствах, локальная версия остаётся под исходным именем, а облачная сохраняется рядом:

```text
Заметка.remote-conflict-a1b2c3d4-2026-09-16T12-00-00-000Z.md
```

Пользовательские файлы на Яндекс.Диске удаляются в корзину. Служебная папка блокировки удаляется безвозвратно, чтобы не засорять корзину.

Перед первым использованием рекомендуется сделать резервную копию хранилища.
